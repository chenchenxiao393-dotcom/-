Interactive New Year 2026 Countdown

## 项目简介
这是一个基于浏览器的交互式新年倒计时/祝福展示页面。使用摄像头手势触发粒子形态与照片展示，并支持自定义背景音乐。

## 主要特性
- **手势交互**：通过 MediaPipe Hands 识别手指数量，切换粒子形状（数字/拳头/张开手）并触发照片展示与祝福语循环。
- **粒子文字/形状**：使用 three.js 渲染大量粒子并排列成数字或手势形状。
- **照片墙**：加载 `docs/` 下的照片（photo1.jpg...）并在触发时展示与旋转。
- **背景音乐**：支持本地上传或粘贴 URL 播放，播放状态会保存在本地存储。

## 依赖（运行时通过 CDN 加载）
- `three.js`（用于 WebGL 渲染）
- `@mediapipe/hands`（手势检测）
- `tween.js`（平滑动画）

这些依赖在 `index.html` 中通过 CDN 引入，无需额外安装。

## 使用说明
1. 在浏览器中打开项目根目录下的 `index.html`（推荐使用最新的 Chrome/Edge）。
   - 直接双击打开文件或通过本地静态服务器（推荐）。
2. 允许页面访问摄像头。
3. 在页面右下角可上传本地音乐或粘贴音乐 URL，回车或选择后点击“播放”。
4. 将手放入摄像头画面，使用不同手指数量触发不同效果：
   - 0 指（握拳）：拳头形态（FIST）。
   - 1/2/3 指：分别变为数字形态（`1`、`2`、`3`）。
   - 从拳头变为张开手（OPEN）：触发照片展示与祝福语循环（会锁定交互以保证动画完整）。

## 本地开发（推荐在简单服务器下运行）
如果需要通过本地服务器打开（以避免某些浏览器对本地文件的限制）：

Python 3 简单静态服务器（在项目根目录运行）：

```bash
python -m http.server 8000
# 然后在浏览器访问 http://localhost:8000
```

或使用 Node.js 的 `http-server`：

```bash
npx http-server -p 8000
```

## 资源说明
- 主页面：`index.html`
- 照片资源：`docs/photo1.jpg`、`docs/photo2.jpg` … （最多使用 `PHOTO_COUNT` 配置的数量）

## 可配置项
- 在 `index.html` 中可调整 `PHOTO_COUNT`、粒子数 `P_COUNT`、照片分布范围等参数以改变效果与性能平衡。
